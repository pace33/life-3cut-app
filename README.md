# 3컷 사진 놀이 사용 방법

이 웹 앱은 특수학교 초등학생이 쉽게 사용할 수 있도록 만든 인생네컷 스타일 3컷 촬영 앱입니다.

## 실행하기

카메라 권한 때문에 브라우저에서 `localhost` 주소로 여는 것을 권장합니다.

1. `outputs/life-3cut-app` 폴더를 엽니다.
2. 간단한 로컬 서버로 폴더를 실행합니다.
3. 브라우저에서 표시된 주소를 엽니다.

Codex에서 확인할 때는 준비된 로컬 주소를 사용하면 됩니다.

## 사용 순서

1. `카메라 켜기`를 누릅니다.
2. 브라우저가 물어보면 카메라 사용을 허용합니다.
3. `사진 찍기`를 누르면 3초 카운트다운 뒤 사진이 찍힙니다.
4. 총 3장을 찍으면 꾸미기 화면으로 이동합니다.
5. 1번, 2번, 3번 사진 중 하나를 고르고 스티커를 추가합니다.
6. 사진 보정 버튼으로 밝게, 선명, 따뜻, 흑백 효과를 고릅니다.
7. 사진틀에서 깔끔, 파스텔, 필름 중 하나를 고릅니다.
8. 스티커는 손가락이나 마우스로 끌어서 옮길 수 있습니다.
9. 스티커를 다시 누르면 그 자리에 고정됩니다.
10. `사진 저장`을 누르면 완성된 세로형 3컷 이미지가 현재 브라우저의 사진 보관함에 저장됩니다.
11. 상단의 `사진 보기`를 누르면 저장한 사진을 크게 보거나 삭제할 수 있습니다.
12. `다시 찍기`를 누르면 처음부터 새로 촬영합니다.

## 스탠바이미에서 촬영하기

스탠바이미의 webOS 브라우저는 일반 웹사이트에 USB 카메라 영상을 제공하지 않으므로
휴대폰을 무선 카메라로 연결할 수 있습니다.

1. 스탠바이미에서 `휴대폰 카메라 연결`을 누릅니다.
2. 휴대폰으로 QR코드를 찍거나 `remote-camera.html`을 열고 연결 번호를 입력합니다.
3. 휴대폰에서 `카메라 시작`을 누르고 카메라 권한을 허용합니다.
4. 스탠바이미의 `휴대폰으로 촬영` 버튼을 누르면 두 화면에 3초 카운트다운이 나옵니다.
5. 촬영된 사진이 스탠바이미로 전송되면 다음 촬영을 진행합니다.

전송된 임시 사진은 스탠바이미가 내려받은 직후 빈 이미지로 덮어씁니다. 연결은 30분 뒤 만료됩니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 밝고 쉬운 UI 디자인
- `app.js`: 카메라 촬영, 카운트다운, 스티커 이동, 사진 보관함 저장·보기·삭제 기능
- `remote-camera.html`: 휴대폰 무선 카메라 화면
- `remote-camera.css`, `remote-camera.js`: 휴대폰 촬영 화면과 사진 전송 기능
- `qrcode.js`: QR Code Generator(JavaScript, Kazuhiko Arase, MIT License)

## Android APK

안드로이드용 설치 파일은 `dist/eeun-efestival-photo.apk`입니다.
Android 8.0 이상에서 실행되며, 웹 앱 전체가 포함되어 인터넷 없이 사용할 수 있습니다.
완성 사진은 기기의 `Pictures/EeunPhotoBooth` 폴더에 저장됩니다.
